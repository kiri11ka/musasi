☁️ Синхронизация двух телефонов

Отметки сохраняются в файл data.json в вашем репозитории на GitHub, поэтому оба телефона видят одно и то же. Токен хранится только в этом браузере.

Как получить токен
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выбрать этот репозиторий.
  3. Permissions → Add permissions → Contents: Read and write.
  4. Срок действия с запасом на лечение, скопируй токен сюда.
