☁️ Синхронизация двух телефонов

Отметки сохраняются в файл data.json в вашем репозитории на GitHub, поэтому оба телефона видят одно и то же. Нужно один раз вставить токен на каждом телефоне. Токен хранится только в этом браузере.

Как получить токен
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выбрать этот репозиторий.
  3. Permissions → Repository → Contents: Read and write.
  4. Срок действия поставь с запасом на курс (например, 90 дней), скопируй токен сюда.
